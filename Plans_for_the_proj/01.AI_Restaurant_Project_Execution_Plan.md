# Project Vision

Develop a **production-ready AI-powered Restaurant Recommendation
Platform** that intelligently recommends the best restaurants within a
**3 km radius** based on the user's **live GPS location**, personal
preferences, cuisine, ratings, budget, and contextual information.

The application should provide a premium user experience comparable to
**Google Maps, Uber Eats, Airbnb, and Zomato**, while being built
entirely using **100% Free and Open Source Software (FOSS)**.

# Core Development Principles

The project **must only use free and open-source technologies**.

### Rules

-   Supabase

# Immediate Priority

The team should **focus only on Phase 2 and Phase 3**.

Do **not** build the backend, AI, GIS logic, or database yet.

The first milestone is to deliver: 1. A complete design system. 2. A
premium UI/UX. 3. A production-ready React frontend using mock data. 4.
Fully responsive layouts. 5. Pixel-perfect light and dark themes. 6.
Reusable components.

Only after the frontend is approved should the project move to
Authentication, Backend, Database, GIS, AI, and LLM integration.
